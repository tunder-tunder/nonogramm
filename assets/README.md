# PNG assets

Проект уже настроен на автоматическую загрузку будущих PNG-файлов. Имена и пути
регистрочувствительны, поэтому заменяйте плейсхолдеры файлами с точными именами.

## Компаньоны

Положите прозрачные PNG в `assets/companions/`:

- `chapter_01_a.png`, `chapter_01_b.png`;
- `chapter_02_a.png`, `chapter_02_b.png`;
- `chapter_03_a.png`, `chapter_03_b.png`;
- `chapter_04_a.png`, `chapter_04_b.png`;
- `chapter_05_a.png`, `chapter_05_b.png`.

Рекомендуемый размер исходника: от 256×256 px, прозрачный фон, персонаж с запасом
в несколько пикселей по краям. В уровне изображение вписывается в слот с сохранением
пропорций и автоматически использует существующую анимацию прыжка.

## Галерея

Положите полноразмерные изображения в `assets/gallery/`:

- `chapter_01.png`;
- `chapter_02.png`;
- `chapter_03.png`;
- `chapter_04.png`;
- `chapter_05.png`.

Рекомендуемое соотношение сторон — 16:9, например 1920×1080 px. Галерея создаёт
уменьшенное превью автоматически; по клику изображение открывается поверх интерфейса
в полноэкранном режиме. Пока файла нет, показывается безопасный PNG-плейсхолдер.
